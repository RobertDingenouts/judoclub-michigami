## Stap 3: Data mapping document

### 3A. Create `src/data/technique-images.ts`
```typescript
export interface TechniqueImage {
  techniqueId: number;  // id uit techniques.ts
  categoryKey: string;  // 'heupworpen', 'beenworpen', etc.
  filename: string;     // bestandsnaam in public/techniques/

}
```
